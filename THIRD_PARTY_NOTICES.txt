DS1K test build includes and modifies code from DeadSpace2008Fixes:
https://github.com/seamusduncmcgrath/DeadSpace2008Fixes
Upstream revision: 975836ed1c7de5fd447d3694324fecdc870c8719

It also redistributes SDL3.dll and embeds MinHook through that project.
The generated game font atlases use NanumBarunGothic Regular, Copyright (c)
2010 NAVER Corporation, under the SIL Open Font License 1.1.
The complete applicable license notices are included under third_party:

- DeadSpace2008Fixes/LICENSE
- licenses/MinHook-BSD-2-Clause.txt
- licenses/SDL3-zlib.txt
- NanumBarunGothic/OFL-1.1.txt
- licenses/NSIS-COPYING.txt
- licenses/VPatch-zlib.txt

The Windows installer is built with NSIS and uses the bundled VPatch plug-in
to generate patched STR files from a user's supported original game files.
