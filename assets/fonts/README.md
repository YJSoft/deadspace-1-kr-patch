# 폰트 입력 자산

`NanumBarunGothic.ttf`는 세 게임 UI 폰트 아틀라스를 생성할 때 사용하는 원본 입력
파일이다. 빌드 결과물이 아니며 재현 가능한 자산 생성을 위해 저장소에 포함한다.

- 파일: `NanumBarunGothic.ttf`
- SHA-256: `9B872773134E2E4D8C0B17021266786576DB06C843EDE0D0B523B214A450756C`
- 라이선스: SIL Open Font License 1.1
- 전문: `third_party/NanumBarunGothic/OFL-1.1.txt`

Reserved Font Name 조건을 지키고, 글꼴을 수정해 같은 이름으로 재배포하지 않는다.
