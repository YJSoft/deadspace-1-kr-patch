# 번역 CSV 편집 안내

`dead_space_ko.csv`가 게임 번역의 단일 편집 원본이다. UTF-8 BOM이 포함된 표준 CSV로,
Excel·LibreOffice Calc·텍스트 편집기에서 열 수 있다.

열 구성:

- `id`: 게임의 32비트 문자열 ID. 변경하지 않는다.
- `english`: Steam 원본 영어 문장. 번역 참고용이며 게임에 출력되지 않는다.
- `translation`: 실제로 게임에 출력할 UTF-8 한국어 문장.

쉼표, 큰따옴표 또는 줄바꿈이 포함된 셀은 CSV 규칙에 따라 큰따옴표로 감싸져 있다.
셀 안의 큰따옴표는 `""`처럼 두 번 기록한다. 스프레드시트 프로그램은 이를 자동으로
처리한다.

기존 한글패치 `Launcher.xml`에서 영어 원문이 일치한 번역은 가져오되, 중국어 패치의
공백 제거 방식 때문에 쓰였던 전각 공백(`U+3000`)과 탭은 일반 ASCII 공백으로 바꾸고
연속 공백은 하나로 합친다. 완전 일치를 우선하고, 공백만 다른 문장은 공백을 무시해
보조 매칭한다.

Steam 원본 5,045개 ID 가운데 번역 가능한 4,562개를 CSV에 넣었다. 원본에서 UTF-8로
해석되지 않는 95개 중 `0xA0` 비분리 공백만 일반 공백으로 바꾸면 UTF-8이 되는 12개를
복구한다. 이 때문에 예전 생성기에서 빠졌던 일부 오디오 로그 자막도 ID별 번역이
가능하다. 나머지 잘못된 UTF-8 83개, 한 글자 396개와 `[]`처럼 문자와 숫자가 전혀 없는
항목 4개는 제외하고, 빌드할 때 해당 483개 원본 바이트를 그대로 보존한다.

번역을 보완할 때는 해당 행의 `translation` 셀만 수정한다. 행 삭제, ID 변경, 중복 ID
추가는 빌드 오류로 처리된다. 번역 셀을 빈칸으로 두는 것도 허용하지 않는다.

기존 패치는 영문 문장만으로 번역을 찾았기 때문에 같은 영문에 서로 다른 번역이 있는
경우 첫 항목만 사용할 수 있었다. 초기 CSV도 호환성을 위해 첫 번역을 넣었지만, 이제
각 행에 ID가 있으므로 문맥에 맞게 행별로 독립 수정할 수 있다.

기존 패치 XML에서 CSV를 다시 생성하려면 다음 명령을 사용한다.

```bat
generate-translations.cmd original-lh2 Launcher.xml translations\dead_space_ko.csv
```

수정해 온 CSV를 유지하면서 새로 발견된 ID만 추가하려면 네 번째 인수로 기존 CSV를
지정한다. 동일한 ID의 `translation`은 기존 파일에서 그대로 보존한다.

```bat
generate-translations.cmd original-lh2 Launcher.xml new.csv translations\dead_space_ko.csv
```

전체 자산 생성기는 CSV의 모든 ID가 LCH2에 존재하는지 검사하고, 영어 참고문이 원본과
다른 행의 수를 보고한다.
